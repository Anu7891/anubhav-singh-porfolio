# Anubhav Singh — Portfolio (Dark)

Dark, premium developer portfolio — gradient accents, glass pill nav, ⌘K
command palette. Next.js App Router · TypeScript · Tailwind CSS v4.

## Features

- Fixed glass pill navbar with working dark/light theme toggle (persisted)
- ⌘K / Ctrl+K command palette: jump to sections, copy email, open links
- Scroll progress bar, floating hero chips, orbit rings, availability badge
- Alternating experience timeline with center line and glowing markers
- Animated skill bars and count-up stats (IntersectionObserver, no libraries)
- Bento project grid with browser-mockup thumbnails and hover actions
- Contact form that opens a pre-filled email (no backend needed)
- Accessible: skip link, focus rings, semantic HTML, prefers-reduced-motion

## Getting started

```bash
npm install
npm run dev
```

All content lives in `src/lib/data.ts` — edit once, updates everywhere.
Add your `resume.pdf` to `public/`. Deploy by importing to Vercel.
